Protección de datos

Consentimiento del ciudadano

Antes de continuar, es importante que el ciudadano conozca cómo se tratarán sus datos:

  • Se capturarán datos de identidad (nombre, cédula, fecha de nacimiento, sexo y lugar de nacimiento).
  • Se capturará una firma manuscrita como respaldo del registro.
  • Los datos se utilizarán únicamente para los fines del proceso de afiliación del partido.
  • Las imágenes de la cédula se usan solo para la extracción de datos y no se almacenan permanentemente.
  • El responsable del tratamiento es Organización Política.
  • El ciudadano puede ejercer sus derechos de acceso, rectificación y oposición.
No se garantiza una protección absoluta, pero se aplican medidas técnicas razonables para resguardar la información, conforme a la legislación dominicana aplicable sobre protección de datos personales.
